快速开始

从源码或 Windows 安装包安装，配置模型，打开第一个研究工作区。

OhPie 有两种获取方式：从仓库拉源码运行，或使用 Windows x64 桌面安装包。两条路径终点相同：本机上的一个本地服务、你配置好的模型，以及一个把每个结果都写成普通文件的工作区目录。

需要准备什么

需要 用途
Git 克隆仓库。
Node.js 22.19.0 或更高 运行本地服务与构建。
一个模型供应商 通过 OAuth 登录，或填入 API Key。
Windows x64 仅桌面安装包需要。
Python 或 R 仅本地数据分析需要，并且要装好分析所导入的包。
网络 仅模型调用与你启用的外部 MCP 服务需要。

从源码运行

启动器会选择可用端口、输出地址并打开浏览器。当前服务记录写入 .next/ohpie-server.json，因此始终能找到这份检出目录对应的健康进程。

需要桌面窗口时，保持该终端运行，另开一个终端：

npm run dev -- --no-open、npm run dev -- --port 8080 这类参数必须在启动前确定。一份检出目录共用一个开发服务和同一个 .next 目录，修改参数前先停止正在运行的进程。

构建桌面安装包

命令 产物
npm run dist:dir 位于 dist/win-unpacked/OhPie.exe 的便携应用目录。
npm run dist:win 便携目录，以及 dist/ 下的 NSIS 安装器。

便携目录必须整体保留，从目录内启动 OhPie.exe。安装器还会在 ~/.ohpie/mcp/ 下准备 Puppeteer、ToolUniverse 与 BioMCP 的用户级环境；该步骤需要联网，并会保留已有的 MCP 配置选择。目前没有 macOS 或 Linux 安装包。

首次运行

  1. 打开研究工作区。 为课题或论文选一个文件夹，让 OhPie 初始化工作区目录中描述的研究结构。
  2. 配置模型。 在**模型（Models）**中登录供应商或填入 API Key，再选择模型与推理强度。
  3. 按需填写科研凭据。 设置 → 凭据保存文献与数据库的 API Key、联系邮箱。
  4. 测试任务需要的服务。 设置 → MCP 可逐项测试连接；项目作用域的服务遵循工作区信任规则。
  5. 提出一个真实任务。 输入需求或选择快捷操作，然后在对话旁的画布中打开生成的文档、笔记本、图或图表。

界面支持英文、简体中文与繁体中文。切换语言不会改变文件位置，也不会改变已选择的模型。
