实验凭证

Material Passport 记录了什么，以及它不证明什么。

一张图在文件夹里，和一张图能追回到它的代码与输入，是两种完全不同的东西。实验凭证（Experiment Provenance）负责把后者变成默认。

记录什么

对受支持的本地分析，每登记一个产物就写入一条记录：

字段 内容
artifact 保存的文件（图、表、报告）
code 产出它的归档代码单元或脚本
inputs 分析声明的数据输入及其指纹
runtime 解释器、依赖包版本、宿主信息

全部汇入一个文件：

它是纯文本，可以进版本库、可以 diff、可以在投稿时作为补充材料。

三个状态，不要混为一谈

  1. 执行：代码跑完没有报错。
  2. 登记：产物与代码、输入、环境建立了可查的关联。
  3. 验证：方法合适、统计正确、结论站得住。

OhPie 自动完成前两件，第三件永远由研究者负责。把三者当成一件事，是科研自动化里最常见的错误。

什么时候不会有记录

  • 手动跑脚本、在外部 IDE 里出图，然后拖进目录——这是外来文件，不在登记范围。
  • 服务侧完成的分析（例如外部 MCP 服务自己跑的任务），凭证由服务管理。
  • 你关掉了登记，或分析不满足登记条件。

没有记录不代表文件有问题，只代表它现在不可追溯。需要追溯时，重跑一遍并归档。

诚信闸门

Stage2.5学术诚信闸门 会在一份分析或稿件进入下一阶段前检查：结论是否有对应产物、图是否与代码一致、声称是否有支撑。它列出的是缺口，不是判决。

怎么看

  • 成果面板里每个可登记产物都能看到它的凭证摘要。
  • 直接打开 passport.yaml 看全部记录。
  • 用对话问"这张图的凭证是什么"，模型读的是同一份文件。

凭证能防"我记得是这版代码"，不能防"方法本身就选错了"。后者需要审稿人和你自己。
