画布与文件

右侧标签能打开哪些格式，哪些会随文件刷新。

右侧不是预览窗口，是工作台的一部分。它读的是工作区里的真实文件，所以你在这里看到的图和写在磁盘上的图是同一份。

支持的格式

类型 能做什么
PDF 滚动阅读、缩放，配合对话做逐页精读
DOCX 查看正文与结构，适合读合作者发回的稿件
Markdown / LaTeX 渲染阅读；LaTeX 保留公式结构
Jupyter 笔记本 逐单元展开代码与输出，折叠长输出
CSV / TSV 虚拟化表格视图，大文件也不会一次渲染全部行
XLSX 只读列出工作表名称，不解析整本数据
图片 / 音视频 直接预览，用于核对图件
Draw.io 打开 .drawio / .dio 并可编辑保存
终端 在工作区目录里执行命令
子代理 阅读子代理的完整对话

标签行为

  • 左侧文件树、对话里的路径、@ 引用都能打开标签。
  • 同一个文件重复打开会复用已有标签，不会开出一排重复项。
  • 标签可以关闭、切换，文件被外部修改后内容会刷新。
  • 文件编辑器对产物是只读打开，除非你明确用编辑类工具去改。

Draw.io

.drawio 和 .dio 在画布里可以直接编辑：拖节点、连线、改文字，保存写回原文件。技术路线图、流程图、实验设计图都用它，好处是产物是 XML，可以进版本库。

Notebook

.ipynb 以单元为单位展示：Markdown 说明、代码、输出（文本、表格、图）分开折叠。分析工作室里还能继续执行单元，变量在内核里保留。

终端

终端标签以工作区为当前目录启动，可以跑 git status、查看文件、执行脚本。它和应用自己的命令执行环境是隔离的：宿主进程的敏感变量不会传进去。

成果面板

成果面板把 experiments/4_results/ 下的图、表、报告聚到一处，按类型浏览，直接打开。它只是索引，文件仍在原来的目录里。

画布不会替你整理文件。产物落在哪个目录，取决于你（或技能包）在请求里怎么说——目录约定见研究工作区。
