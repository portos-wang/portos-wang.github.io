排错手册

按层定位：启动、模型、MCP、内核、画布、打包，各自的症状与处理。

出问题时先确定哪一层断了，比反复重装有效。OhPie 的链路是：桌面/服务 → 模型 → 工具（MCP）→ 内核 → 画布 → 打包。每一层的症状不一样。

启动层

症状 多半原因 处理
浏览器打不开地址 端口被占用、启动失败 看终端输出；确认 .next/ohpie-server.json 里的端口
第二次 npm run dev 卡住 同一检出目录只允许一个开发服务 复用已运行的服务，或先停掉再启动
桌面窗口空白 后端服务没起来 关掉窗口重新启动，或先手动跑 npm run dev
Module ... factory is not available 浏览器里的旧 HMR 图 硬刷新页面，不要急着重启服务

模型层

症状 多半原因 处理
401 / 403 令牌过期或密钥错误 重新登录或重填 Key，再点测试
一直转圈无输出 代理拦截、网络不可达 检查 HTTP_PROXY / NO_PROXY，本地地址要排除
模型不在列表里 供应商目录没刷新或模型被关掉 刷新目录；检查模型开关
上下文很快耗尽 模型窗口小或工具结果太长 换更大窗口的模型，或先压缩

MCP 层

症状 多半原因 处理
Test 超时 服务没启动或地址不对 先在应用外手动跑一次服务命令
command not found 桌面应用没继承新 PATH 填绝对路径，重新 Test
连上了但没工具 服务启动失败或需要凭据 看服务自身日志；补连接 env
项目作用域不生效 未通过工作区信任 重新打开项目，确认信任提示

内核层

症状 多半原因 处理
ModuleNotFoundError 该环境没装包 在项目环境里装，或切换解释器
内核重启后变量丢失 进程退出了 变量只在运行期保留，重跑上游单元
找不到 Python / R 未安装或不在 PATH 安装解释器，或在设置里指定路径
中文路径报错 编码问题 路径改用 ASCII，或显式设置编码

画布层

症状 多半原因 处理
大 CSV 打开很慢 行数超出舒适范围 用分页/抽样，或先聚合再查看
笔记本输出空白 未执行的单元 在分析工作室里执行一次
XLSX 只有表名 这是设计如此 工作表清单只读，数据请导出 CSV

打包层

症状 多半原因 处理
dist:win 失败 开发服务正在写 .next/ 在独立 worktree 里打包
安装器卡在 MCP 准备 网络不通或下载失败 安装器可重试，日志在 ~/.ohpie/mcp/install.log
打包后启动白屏 打包资源缺失 用 npm run test:desktop 做冒烟测试
