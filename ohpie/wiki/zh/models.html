模型与供应商

登录或填 Key、启用哪些模型、默认模型与推理强度、代理。

模型配置分两层：供应商决定能用哪些模型，模型开关决定列表里显示哪些。两者都在设置里改，不用编辑配置文件。

供应商

支持两类接入方式：

方式 适用 注意
OAuth 登录 提供账号授权的供应商 浏览器完成，令牌存在本机
API Key 提供密钥的供应商 密钥加密保存在 ~/.ohpie/
自定义供应商 OpenAI 兼容端点 需要 base URL 与模型名

自定义供应商写在 ~/.ohpie/agent/models.json，可以在设置里的 models 配置界面直接编辑，也能贴 JSON。

模型开关

供应商可能返回几十个模型，模型开关决定侧栏与选择器里出现哪些。选中的模型会出现在对话的模型选择器里；没选的不会消失，只是不占位置。

默认模型与推理强度

  • 默认模型：新会话开始时用哪个。
  • 推理强度：默认档位，越低越快、越高越深。
  • 单次对话里改模型只影响这次会话。

可用的推理档位由模型目录决定，不同模型不一样。切换模型后会回到该模型支持的默认档。

刷新目录

供应商上下线模型是常态。刷新目录会重新拉取可用列表，并保留你已有的开关选择；新出现的模型默认不启用。

几个字段值得填对：api 决定请求格式（如 anthropic-messages 与 OpenAI 兼容格式不同），contextWindow 与 maxTokens 决定什么时候开始压缩，input 里没有 image 的模型不能收图片。

推理档位有两层：thinkingLevels 声明某个模型支持哪几档，thinkingLevelMaps 把界面档位映射到供应商的真实取值（null 表示不支持）。映射写错会出现"选了高档但实际没生效"。

凭据

模型密钥与科研数据库密钥分开管理：模型在设置 → 模型里配，科研 API 在设置 → 凭据里配。后者会被 ToolUniverse、BioMCP 与 w77-nfsc-pipeline 自动取用。

代理

服务端的模型与 API 请求遵循 HTTP_PROXY、HTTPS_PROXY、NO_PROXY。启动前设好，本地地址（localhost、127.0.0.1）要排除，否则本地服务会被代理拦住。

费用与额度

OhPie 不代收费用：账单发生在你选的供应商那里。设置里的用量提示来自供应商返回的信息，仅供参考，以供应商后台为准。

换模型会改变回答风格与工具调用习惯。关键分析换模型后，至少重跑一次核心步骤，确认结论不是模型特性带来的。
