文献与证据

检索、筛选、精读、引文核验，以及反证检索。

文献工作的难点不是"找到论文"，而是读完之后能说清哪条证据支持哪句话。OhPie 把这条链拆成几个可以分别执行的动作。

检索与来源

文献来源通过 MCP 服务或 API 凭据接入（PubMed / OpenAlex / Semantic Scholar 等）。检索结果会连同策略一起记录，而不是只留一串链接：

  • 检索式、数据库、日期范围
  • 命中数量与筛选后的数量
  • 全文可得与仅摘要可得分开标注

筛选

PRISMA 2020 双盲初筛（快捷操作或 academic-research-skills）按 PRISMA 流程做两轮筛选，记录排除理由与数量。产出的是可写进 Methods 的流程图数据，不是"我看了一些文章"。

精读

方式 快捷操作 得到什么
X 光透视 X光透视精读 按图、方法、结论拆解，指出证据强度
逐图精读 图表证据审计 逐个面板核对，标出可疑与缺失
全文伴读 双语全文伴读 中英对照，边读边注
结构化抽取 试验设计主体抽取 对象、分组、样本量、干预、终点逐字段

证据表长什么样

一张能用的证据表至少包含这些列：

列 作用
来源 作者、年份、DOI/PMID
设计 队列 / RCT / 横断面 / 动物 / 体外
样本 物种、n、人群特征
终点 主要终点与测量方式
结果 效应量与区间，不只写 p
位置 页码/图号，方便回查
判定 支持 / 部分 / 相反 / 不可用

最后一列是这张表的用处：没它，表只是摘录。

常见误用

  • 把摘要当全文：摘要常常省掉限制条件，用它做证据表会系统性高估。
  • 把综述当原始研究：综述能帮你找文献，不能当某项结果的证据。
  • 只找支持性文献：不找反证，Discussion 一定会被审稿人补上。
  • 不记检索式：半年后无法重现"我到底搜了什么"。

引文核验

论点配引与声称审计 做的是声称级核对：把正文里的每一句论断拆出来，检查引用它的文献是否真的支持这句话，以及支持到什么程度。常见结论有三种：

  • 支持（并说明支持的是哪一部分）
  • 部分支持（条件、人群或终点不一致）
  • 无法判定（没有全文、来源不可达、标识符有歧义）

第三种不是失败，是需要补证据的任务项。

反证与边界

反证与边界检索 主动找相反结果、适用边界、替代解释和方法学问题。写 Discussion 时它比再找十篇支持文献有用。

谱系与选题

  • 文献溯源：从种子论文追前驱与后续，核对真实引用关系。
  • 选题撞车检测：跨术语检索相近工作，逐篇比较拟议贡献。
  • 立项前证据评估 / 选题地狱抗辩：在正式投入前把证据基础问一遍。

检索成功不等于证据成立。数据库返回的是记录，不是结论；每一条"支持"都要能指到具体位置。
