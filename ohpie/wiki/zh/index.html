科研流程

四个阶段、一条回边，以及一份并不构成结论的来源记录。

 04

技能包

25 个内置技能包，按真实用途分组，附加载方式与自写规范。

生物信息 MCP

构建与维护

常见问题

关于平台、依赖、数据位置、代理与许可的简短回答。
不粉饰的部分
代码可以跑通，文件可以登记，而结论仍然可能是错的。

OhPie 记录执行过程与来源，但不认证方法、引文或统计量是否正确。同行评审与引证核查技能包的作用，是要求证据，而不是要求认同。

四层结构

一条流程，四层职责。除非你配置了需要联网的服务，数据不会离开本机。

工作区

科研材料放在普通文件夹：literature、experiments、manuscript、notes。

智能体

Pi Coding Agent 运行时读取工作区，并把真实文件写回工作区。

内核

Python 或 R 在本机运行，内核开着时变量跨代码单元与对话轮次保留。

成果

图、表、笔记本与来源记录落在手稿能引用的位置。
