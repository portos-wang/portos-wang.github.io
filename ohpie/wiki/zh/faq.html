常见问题

关于平台、依赖、数据位置、代理与许可的简短回答。

有 macOS 或 Linux 安装包吗？

目前没有。桌面打包面向 Windows x64，产出便携目录与 NSIS 安装器。从源码运行在任何装有 Node.js 22.19.0 或更高版本的系统上都可以，但 Electron 外壳只在 Windows 上打包与验证过。

需要安装 Python 或 R 吗？

只有本地数据分析需要，且需要分析所导入的依赖包。聊天、文档阅读、文件画布与 MCP 工具调用都不需要解释器。分析内核使用机器上已安装的 Python 与 R。

关闭窗口会停止任务吗？

取决于你选择的关闭行为：应用可以缩到系统托盘，也可以退出。从托盘退出会停止应用拥有的后端进程；运行在外部服务上的任务按那些服务的规则继续或停止。

模型请求可以走 HTTP 代理吗？

可以。服务端模型与 API 请求遵循标准的 HTTP_PROXY、HTTPS_PROXY 和 NO_PROXY。请在启动 OhPie 前设置，并把 localhost、127.0.0.1 等本地地址排除在代理之外。

对话和设置存在哪里？

对话存在项目里：<workspace>/.ohpie/agent/sessions/。共享设置、供应商凭据、全局技能与插件、已知工作区记录存在 ~/.ohpie/。研究工作区一页有完整表格，也包括如何覆盖这两个位置。

这是 pi-web 的分支吗？

界面基于 pi-web 的定制分支，智能体引擎是集成的 Pi Coding Agent。OhPie 增加的是研究工作区结构、分析画布、来源记录、桌面生命周期与独立的 .ohpie 存储。

需要账号或订阅吗？

不需要 OhPie 账号，也没有 OhPie 云端。费用发生在你配置的模型供应商那里；外部科学服务可能有自己的密钥与配额。应用本身以 MIT 许可证发布。

可以离线使用吗？

本地模型对话、文件阅读、画布与本地 Python/R 分析不需要网络。调用托管模型、文献检索和任何 MCP 服务都需要联网。安装器准备的服务环境只需下载一次。

为什么引文核查有时返回"无法判定"？

因为证据不可得，而不是工具悄悄失败了。核查只能确认它读得到的内容：没有全文、来源打不开或标识符有歧义时，诚实的结果就是"无法判定"，并附上解决它还需要什么。请把它当成任务清单，而不是结论。
