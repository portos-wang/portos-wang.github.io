Experiment provenance

What the Material Passport records, and what it does not prove.

A figure sitting in a folder and a figure traceable to its code and inputs are two different objects. Experiment provenance is what makes the second one the default.

What is recorded

For supported local analyses, each registered artifact writes one entry:

Field Content
artifact The saved file (figure, table, report)
code The archived cell or script that produced it
inputs Declared data inputs and their fingerprints
runtime Interpreter, package versions, host details

All of it collects in one file:

It is plain text: it can be versioned, diffed, and attached as supplementary material.

Three states, kept separate

  1. Executed — the code ran without error.
  2. Registered — the artifact is linked to code, inputs and environment.
  3. Validated — the method is appropriate, the statistics are right, the conclusion holds.

OhPie does the first two automatically. The third remains the researcher's job. Treating them as one thing is the most common failure in research automation.

When there is no record

  • A script run by hand, a figure made in another IDE and dragged in — these are foreign files, outside registration.
  • Analysis performed service-side (for example by an external MCP service) — that service owns the record.
  • Registration was off, or the analysis did not meet the conditions for it.

No record does not mean the file is wrong; it means it is currently untraceable. If it needs to be traceable, re-run it under the workspace.

Integrity gates

Stage 2.5 integrity gate checks, before an analysis or draft moves to the next stage, whether claims have artefacts, figures match code, and assertions have support. It lists gaps; it does not issue verdicts.

Where to look

  • The artifacts panel shows a provenance summary for each registered artifact.
  • passport.yaml holds every entry.
  • Ask the conversation what a figure's provenance is — the model reads the same file you would.

Provenance prevents "I think it was this version of the code". It cannot prevent choosing the wrong method in the first place. That still needs a reviewer and you.
