Troubleshooting

Locate the layer first — startup, models, MCP, kernel, canvas or packaging.

When something breaks, find which layer is broken before reinstalling anything. The chain is: desktop / server → model → tools (MCP) → kernel → canvas → packaging. Each layer fails differently.

Startup

Symptom Likely cause Fix
The address will not open Port taken, or startup failed Read the terminal; check the port in .next/ohpie-server.json
A second npm run dev hangs One dev server per checkout Reuse the running server, or stop it first
Desktop window is blank Backend did not start Quit and relaunch, or run npm run dev first
Module ... factory is not available Stale HMR graph in that tab Hard-reload the page before restarting the server

Models

Symptom Likely cause Fix
401 / 403 Expired token or wrong key Sign in again or re-enter the key, then test
Spinner with no output Proxy blocking, unreachable host Check HTTP_PROXY / NO_PROXY, keep local addresses outside
Model missing from the list Catalog not refreshed, or switch off Refresh the catalog; check the model switch
Context fills up fast Small window or very long tool output Pick a larger-window model, or compact first

MCP

Symptom Likely cause Fix
Test times out Service not running or wrong address Run the service command manually outside the app
command not found Desktop app inherited an old PATH Use the absolute path, then test again
Connected but no tools Service failed on startup or needs credentials Read the service log; add env to the connection
Project scope ignored Workspace trust not granted Reopen the project and confirm the trust prompt

Kernel

Symptom Likely cause Fix
ModuleNotFoundError Package missing in that environment Install into the project environment, or switch interpreter
Variables gone after a restart The kernel process exited Variables live only while it runs; re-run upstream cells
Python / R not found Not installed, or not on PATH Install it, or point to the interpreter in settings
Errors on a non-ASCII path Encoding Use an ASCII path, or set the encoding explicitly

Canvas

Symptom Likely cause Fix
A large CSV opens slowly Row count beyond the comfortable range Filter or aggregate first, then view
Notebook output is empty Cells were never executed Run them in the analysis studio
XLSX shows only sheet names That is by design The sheet list is read-only; export CSV for data

Packaging

Symptom Likely cause Fix
dist:win fails A dev server is writing to .next/ Package from a separate worktree
Installer stalls preparing MCP Network or download failure Retry in the installer; log at ~/.ohpie/mcp/install.log
Packaged app starts blank Missing packaged resource Run npm run test:desktop as a smoke test

What to include in a report

Be conservative with cache clearing. Deleting .next/ fixes a corrupted build but forces a dev-server rebuild; do not make "reinstall / clear everything" the first step — locate the layer first.
