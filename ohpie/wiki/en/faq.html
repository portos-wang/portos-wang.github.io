FAQ

Short answers about platforms, dependencies, data location, proxies and licensing.

Is there a macOS or Linux build?

Not today. Desktop packaging targets Windows x64 and produces a portable folder plus an NSIS installer. Running from source works anywhere Node.js 22.19.0 or newer is available, but the Electron shell is only packaged and verified on Windows.

Do I need Python or R?

Only for local data analysis, and only with the packages your analysis imports. Chat, document reading, the file canvas and the MCP tool calls work without either interpreter. The analysis kernel uses whatever Python and R are installed on the machine.

Does closing the window stop the work?

It depends on the close behaviour you chose: the app can minimise to the tray or quit. Quitting from the tray stops the backend processes the application owns. Jobs running on external services continue or stop according to those services' rules.

Can model requests go through an HTTP proxy?

Yes. Server-side model and API requests honour the standard HTTP_PROXY, HTTPS_PROXY and NO_PROXY variables. Set them before launching OhPie and keep local addresses such as localhost and 127.0.0.1 outside the proxy.

Where do conversations and settings live?

Conversations live in the project: <workspace>/.ohpie/agent/sessions/. Shared settings, provider credentials, global Skills and Plugins and the known-workspace registry live in ~/.ohpie/. The workspace page has the full table, including how to override both locations.

Is this a fork of pi-web?

The interface is built on a customised fork of pi-web; the agent engine is the integrated Pi Coding Agent. OhPie adds the research workspace layout, the analysis canvas, the provenance record, the desktop lifecycle and the isolated .ohpie storage.

Does it need an account or a subscription?

No OhPie account and no OhPie cloud. You pay whichever model provider you configure, and external scientific services may have their own keys and quotas. The application itself is MIT licensed.

Can I use it offline?

Local chat against a local model, file reading, the canvas and local Python/R analysis work without a network. Model calls to hosted providers, literature search and any MCP service need connectivity. Service environments prepared by the installer are downloaded once.

Why does a citation check sometimes come back “unresolved”?

Because the evidence was not available, not because the tool failed quietly. A claim check can only confirm what it can read: with no full text, no accessible source or an ambiguous identifier, the honest result is unresolved, together with what would be needed to settle it. Treat that as a task list, not a verdict.
