Interface tour

Sessions on the left, conversation in the middle, files on the right — plus every control above the input.

The window always has three parts. The left tells you which project and which conversation, the middle is the conversation, and the right is the files. Seeing all three at once is the difference between a research workbench and a chat box with code in it.

The three areas

Area What is in it What you do there
Left sidebar Session tree, workspace file browser, search, quick entries Start a conversation, switch project, drag a file in
Conversation Message stream, thinking, tool cards, composer Ask, @-mention a file, change model, compact
Canvas Tabs: files, notebooks, images, terminal, subagents Read outputs, cross-check sources, run commands
Top strip Model, tool preset, reasoning level, export, branch Set the conditions for this turn

Composer and quick actions

Above the input sits the quick action bar: prepared research tasks that fill the composer with a prompt you can still edit. They come from research-actions.json, with a global set and a project set where the project wins on name collisions.

  • @ opens the file index and references a workspace file into the turn.
  • / opens the command menu: runtime commands plus commands contributed by loaded skills.
  • Images can be pasted or dropped and travel with the message.
  • While the agent is working, the send button becomes stop, and a new message can either steer (interrupt and redirect) or queue (run after the current turn).

Canvas tabs

Tab Opened from Job
File File tree, links in the conversation, @ results Read and compare; refreshes when the file changes
Analysis studio .ipynb / .qmd in the file tree or artifacts Step through code and outputs cell by cell
Figure or table Anything under figures/ or tables/ Judge whether a panel is publishable
Terminal New terminal tab Run commands in the workspace directory
Subagent The subagent card in the conversation Read what the child actually did

Settings

Settings holds models, credentials, MCP, skills, plugins, subagents and tool switches. Language (English / Simplified Chinese / Traditional Chinese), theme and completion sound are interface preferences.

Language and theme change what you see. They do not move files, relocate sessions, or change the selected model.
