Skill packs

25 bundled packs, grouped by the job they actually do, plus how they load and how to write one.

A Skill Pack is a folder with a SKILL.md and whatever references, scripts and templates that method needs. It is not a prompt snippet: the full body loads only when the agent decides the pack matches the task, which keeps the base conversation small and lets a pack carry real checklists.

OhPie ships 25 packs and 5 plugins. Every pack below is in this repository under builtin-skills/; nothing in the list is a hosted service.

Finding and judging literature

Pack What it does
academic-research-skills The full research cycle: PRISMA 2020 double-blind screening, multi-perspective literature mining, structured drafting, two-stage blind review.
literature-close-read Turns a paper's full text into a structured close-reading report instead of a summary.
literature-lineage Traces predecessors and successors from a seed paper and checks real citations rather than assumed lineage.
claim-challenge-search Searches for counter-evidence, boundary conditions and alternative explanations behind an existing scientific claim.
topic-overlap-check Cross-terminology search for near-identical work before a topic is committed, with the closest work recorded.
research-idea-assessment Compares nearby work first, then searches for support, challenges and a discriminating test.
figure-first-paper-reader Reads a paper figure by figure before re-integrating the narrative, so weak panels surface early.
study-design-extractor Extracts study design field by field — subjects, groups, sample size, intervention, endpoints — keeping quoted evidence.
public-data-access Plans and validates acquisition from GEO/GSE, SRA/ENA, TCGA/GDC, GTEx, DepMap and similar repositories, with a delivery manifest.

Analysis, figures and environment

Pack What it does
analysis-workflow The entry point for cleaning, QC, Python/R statistics, modelling and publication plotting, ending in .ipynb plus .qmd.
figure-integrity Screens figure panels for duplication and reuse and produces evidence views for human review. It reports candidates; it does not declare misconduct.
env-setup Prepares the machine: Python interpreters and virtual environments, R renv, scimaster-cli, and the API credentials the other packs expect.

Writing, review and funding

Pack What it does
nature-skills A journal-standard composite: figure-by-figure X-ray reading, evidence cards, bilingual manuscript companion, literature pipeline and figure conventions.
structured-paper-drafting Workspace-aware drafting: provenance boundaries, the three kinds of gap, self-contained figures, archive locations.
research-peer-review Simulated multi-expert blind review selected by document type, with every comment tied to a location in the text.
w77-nfsc-pipeline NSFC and key R&D programme proposals end to end: policy mining, real literature retrieval, Draw.io roadmaps and Gantt charts, simulated blind review.

Documents, clinical work and tooling

Pack What it does
docx · pdf · pptx Create, read and edit Word, PDF and PowerPoint files, including templates and slide decks.
clinical-trial-protocol-skill Drafts drug, biologic or device protocols from a sourced feasibility assessment and design hand-over.
tooluniverse-clinical-trial-design Defines endpoints, population and controls, checks prior trials and regulatory grounds, then hands over a sourced design record.
find-skills Discovers and installs additional skills when a task needs one that is not bundled.
skill-creator Builds, edits and measures new skills, including description tuning for reliable triggering.
pi-session-pattern-miner Mines past sessions for repeated work and turns it into the smallest deterministic script or skill.
field-onboarding Builds a sourced concept map, evolution path and reading order for an unfamiliar field.

How packs load

Packs are discovered from two scopes, exactly like the rest of the configuration:

Scope Location Typical use
Global ~/.ohpie/skills/ Methods you want in every project.
Project ./.ohpie/skills/ A pack pinned to one study, travelling with the repository.

The agent sees each pack's name and description first and loads the body on demand, so a pack can be long without costing context on every turn. Project entries override or extend global ones with the same name.

A pack supplies method and tool guidance. It does not guarantee that a citation, a statistic or a conclusion is correct — several packs exist precisely to make that gap visible.

Writing your own

Start from skill-creator, keep the SKILL.md frontmatter honest (a description that never triggers is a dead pack), and put long material in references/ rather than in the body. A pack that needs a tool should say what happens when the tool is missing.
