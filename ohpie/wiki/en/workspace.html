The workspace

Ordinary folders hold the research; one hidden folder holds the agent's state.

A Research Workspace is a plain directory. Nothing about it is proprietary: papers are PDFs, analysis is Python or R, figures are images, and the manuscript is text. The only special folder is .ohpie/, which keeps the conversation and the agent's configuration next to the material it operated on.

The folder contract

What each folder is for

Folder Contents Touch policy
literature/ Papers, bibliographic data, screening notes, retrieval code. Append-only in normal use.
experiments/1_original_data/ Raw files exactly as received. Read-only; never overwrite.
experiments/2_cleaned_data/ Reproducible cleaned matrices. Regenerate from raw data.
experiments/3_analysis/ Notebooks, scripts and the exported .qmd pairs. The record of how a number was produced.
experiments/4_results/ Figures, tables and passport.yaml. Publication outputs.
experiments/5_report/ Statistical analysis plans and progress reports. Narrative outputs.
manuscript/ Drafts, proposals, referee material, rebuttals. Living documents.
notes/ Reading notes and figure-audit cards. Per-paper working notes.

Two configuration scopes

Location Holds Travels with the repository
~/.ohpie/ Model configuration, provider credentials, global Skills, Plugins, MCP servers and Quick Actions. No.
./.ohpie/ This project's conversations plus project-scoped Skills, Plugins, MCP servers and Quick Actions. Yes.

Project entries are resolved together with global ones. A project definition overrides or extends the corresponding global configuration, which is how one study can pin a different MCP server or a stricter Quick Action without disturbing anything else.

Conversation history lives inside the project on purpose. Move or clone the repository and the discussion of why a figure changed moves with it.

Backups and sharing

Back up a workspace to keep its research files and its conversation history. Back up ~/.ohpie/ separately for shared settings, credentials and global extensions.

Before sharing or publishing a workspace, read .ohpie/ and the session files for credentials or unpublished material. Archiving a project and publishing a project are different decisions, and .ohpie/ is where the difference shows up.

Advanced runtime overrides
Variable Effect
OHPIE_HOME_DIR Selects the home directory that contains .ohpie.
PI_CODING_AGENT_DIR Explicitly overrides the agent configuration directory.
OHPIE_PROJECT_LOCAL_SESSIONS=0 Disables the default project-local session mode.
OHPIE_PORT Requests a local server port; an occupied port can fall back to an available one.
