Sessions

Project-local history, search, branching and export — including subagent transcripts.

A session is one continuous record of a conversation. OhPie stores it inside the project rather than in one global list, so moving or archiving a study takes its discussion with it.

Where it lives

One .jsonl file per session, recording messages, tool calls, model changes and compaction summaries line by line. A text format means it can be diffed, scripted over, and backed up on its own.

Organising

Action Effect
Rename / alias A readable name in the tree
Pin Keep an active study at the top
Archive Move a finished conversation out of the main list
Project order Decide which workspace comes first
Delete Remove the session and its subagent transcripts

Search

Sidebar search matches the body text of sessions and returns snippets with their session. It searches the records on disk, so a session does not need to be open to be found.

Branching and forking

  • In-session branch: start a new branch from any message; the original stays and you can navigate between branches.
  • Disk-level fork: copy the whole session file into a new one with a random suffix — try a different approach without touching the original record.

The difference is visible on disk: branching shares one session file, forking produces two.

Export

A session can be exported as a single static HTML page with messages, tool calls and results preserved. It is a snapshot for collaborators or for archiving a stage; later changes are not reflected.

Subagent transcripts

When a subagent finishes, its full conversation is stored as its own record and can be opened in the canvas. The parent session keeps one summary card — the detail lives in the child.

New session, branch, or fork

Need Do this Why
A different study New session Clean context
Another approach in the same study Branch from a message Keep the original side by side
A fully independent copy Disk-level fork Separate files, separately deletable
A follow-up Continue the session No need to split

Search tactics

  • Search identifiers (gene names, sample IDs, file names), not whole sentences.
  • Search method names (DESeq2, limma, p.adjust) to find where the reporting convention was agreed.
  • If nothing turns up, remember that a session still being written is not on disk yet.

Before deleting

Deletion is not reversible. Export the HTML first, or back up the workspace: .ohpie/agent/sessions/ is the entire history.

Sessions contain unpublished data, local paths and sometimes credentials. Read before sharing a workspace or an export — the same check you would do before submitting a paper.
