Quick start

Install from source or the Windows package, configure a model, and open your first workspace.

OhPie is distributed as source in this repository and as a Windows x64 desktop package. Both paths end in the same place: a local server on your machine, a model you configured, and a workspace folder where every result is written as an ordinary file.

What you need

Requirement Why
Git Clone the repository.
Node.js 22.19.0 or newer Run the local server and the build.
A model provider Sign in with OAuth or paste an API key.
Windows x64 Only for the packaged desktop application.
Python or R Only for local data analysis, with the packages your analysis imports.
Network access Only for model calls and the external MCP services you enable.

Run from source

The launcher picks a free port, prints the URL and opens your browser. The current server record is written to .next/ohpie-server.json, so you can always find the healthy process for this checkout.

For the desktop window, keep that terminal running and open a second one:

Startup flags such as npm run dev -- --no-open or npm run dev -- --port 8080 must be chosen before launch. One checkout shares one development server and one .next directory, so stop the running process before changing them.

Build the desktop package

Command Output
npm run dist:dir Portable application folder at dist/win-unpacked/OhPie.exe.
npm run dist:win The portable folder plus an NSIS installer under dist/.

Keep a portable folder together and launch OhPie.exe from inside it. The installer additionally prepares Puppeteer, ToolUniverse and BioMCP in a user-scoped environment under ~/.ohpie/mcp/; that step needs network access and preserves existing MCP choices. There is no macOS or Linux installer today.

First run

  1. Open a Research Workspace. Pick the folder for a topic or paper and let OhPie initialize the research directories described in the workspace.
  2. Configure a model. In Models, sign in to a provider or add an API key, then choose a model and a reasoning level.
  3. Add research credentials only if you need them. Settings → Credentials holds literature and database API keys and contact addresses.
  4. Test the services your task needs. Settings → MCP can test each connection; project-scoped servers follow the workspace trust rules.
  5. Ask for something real. Type a request or pick a Quick Action, then open the generated document, notebook, diagram or figure in the canvas beside the conversation.

The interface is available in English, Simplified Chinese and Traditional Chinese. Changing the language does not change where files are stored or which model is selected.
